## ✨ Key Features

1. **Crisp 4K Interactive Before & After Slider**
   - High-fidelity 1-to-1 perspective-matched transformation engine.
   - Smooth drag & touch support powered by zero-distortion CSS `clip-path` masks.
   - Scene switchers for Luxury Penthouse, Modular Island Kitchen, and Minimalist Master Suite.

2. **Dual Theme Engine (☀️ Light & 🌙 Dark)**
   - Instant stateful theme switcher in navbar.
   - **Charcoal / Emerald / Gold** for Dark mode.
   - **Warm Alabaster / Ivory / Forest Green** for Light mode.

3. **Interactive Interior Cost Calculator**
   - Real-time estimation based on apartment configuration (1 BHK to 4 BHK / Villa).
   - Dynamic tier selection: *Essential Modern*, *Premium Contemporary*, *Ultra-Luxury Bespoke*.
   - Room-by-room customization (Modular Kitchen, Master Bed, Living, Dining, Bar Unit, False Ceiling).

4. **Moosapet Factory Interio Showcase**
   - Details of German precision edge-banding, computerized panel saws, boiling-water-proof (BWP) marine ply, and direct factory pricing.

5. **Filterable Portfolio Gallery**
   - Living Rooms, Modular Kitchens, Master Suites, Wardrobes, and Commercial Spaces with lightbox preview capability.

6. **Lead Generation & Floating Actions**
   - Instant Free 3D Estimate Modal with live form validation.
   - Quick WhatsApp (`+91 9177374198`) & Direct Phone calling floating triggers.

7. **Footer Attribution**
   - Proudly carries **"Designed & Developed by Purna"** branding and gold pill badge.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Quick Installation

```bash
# Clone the repository
git clone https://github.com/PCS1010/ls.git

# Navigate into the project directory
cd ls

# Install dependencies
npm install

# Start local development server
npm run dev
```

The app will be running at `http://localhost:5173/`.

### Production Build

```bash
npm run build
npm run preview
```
